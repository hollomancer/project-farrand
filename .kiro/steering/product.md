# Product Overview

This is a multi-agent LLM simulation system that recreates the 1787 Philadelphia Constitutional Convention through historically authentic dialogue among the 55 delegates.

## Core Purpose

Generate real-time debates among historical delegates (Madison, Hamilton, Franklin, Mason, etc.) that are:
- Strictly grounded in primary sources (Farrand's Records, Founders Online)
- Reflective of each delegate's documented personality, ideology, and speaking style
- Limited to knowledge and concepts available by September 17, 1787
- Fully cited with references to historical documents

## Key Differentiator

Historical authenticity through Retrieval-Augmented Generation (RAG). Every dialogue turn must be anchored in 18th-century documents with no anachronistic content.

## MVP Scope

The initial implementation focuses on 7 key delegates (Madison, Hamilton, Mason, Sherman, Morris, Franklin, Washington) debating 3 core topics (representation, executive power, federal vs state authority) to validate the core value proposition before scaling to all 55 delegates.
