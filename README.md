# Constitutional Convention Simulation

A multi-agent LLM simulation of the 1787 Constitutional Convention.

## Overview
This project simulates the debates of the Constitutional Convention using AI agents representing historical delegates.

## Setup
1. Install dependencies:
   ```bash
   pip install -e ".[test]"
   ```
2. Set up environment variables:
   - `HUGGINGFACEHUB_API_TOKEN`
   - `PINECONE_API_KEY`

## Running Tests
```bash
pytest
```
